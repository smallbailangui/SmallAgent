软件工程专业推免项目：构建编程智能体

一、题目

个人独立设计并实现一个编程智能体（Coding Agent）。

该智能体需要通过与大语言模型交互，自主完成以下操作：

读取文件

写入文件

执行命令

完成用户交给它的编程任务

整体效果类似于一个简化版的：

Claude Code

Codex

OpenCode

DeepSeek Harness

功能繁简不限，可以实现得很简单，也可以做得较为完善。

二、实现限制

1. 禁止事项

不得直接在现成 Agent 产品上封装界面。

不得使用任何 Agent 框架或 SDK，包括但不限于：

LangChain

LlamaIndex

OpenAI Agents SDK

Claude Agent SDK

AutoGen

CrewAI

同时，不得依赖 API 服务端托管的代码执行或文件工具，例如：

Code Interpreter

Files API

2. 允许事项

允许使用：

模型厂商提供的 API 客户端库

OpenAI 兼容网关

模型原生的 Tool Calling 接口

Agent 运行时：

调用的模型不限

使用的编程语言不限

3. 必须自行实现的重要逻辑

以下核心逻辑需要自行编写，包括但不限于：

对话历史管理

上下文管理

工具定义

工具的本地执行

模型输出解析

Agent 循环逻辑

循环终止条件

错误处理

面试环节

考核重点总结

这道题本质上不是要求调用一个现成 Agent 框架，而是要求你：

从零实现一个最小但完整的 Coding Agent Harness。

一个基础版本至少可以包含如下流程：

用户输入编程任务
       ↓
构造 Prompt / Messages
       ↓
调用 LLM
       ↓
判断模型是否请求工具
       ↓
执行本地工具
   ├── read_file
   ├── write_file
   └── run_command
       ↓
将工具结果加入上下文
       ↓
再次调用 LLM
       ↓
循环执行
       ↓
模型输出最终答案 / 达到终止条件
       ↓
结束

建议至少确保以下四个部分是自己实现的：

LLM 调用与消息管理

Tool 定义与执行

Agent Loop

错误处理与终止机制

如果这些模块设计清晰，即使功能不复杂，也能够较好地体现你对 Coding Agent 工作原理的理解。
